# Решение задач по физике: Скорость и Ускорение

Интерактивное **веб-приложение** для решения и изучения задач по физике
на тему **равномерное и равноускоренное движение**.

Ранее проект был консольным приложением — теперь он переведён в формат
современного веб-приложения на **Flask**.

## Возможности

- 📚 **Банк задач** — готовые задачи с подробными решениями (равномерное движение, равноускоренное движение, свободное падение).
- 🧮 **Решатель задач** — введите данные, и программа вычислит искомую величину по формулам кинематики.
- 📐 **Справочник формул** — все основные формулы темы «Скорость и ускорение».
- ✏️ **Тест** — проверьте свои знания с автоматической проверкой ответов.

## Установка и запуск

Требуется Python 3.7+.

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Запустите приложение:

   ```bash
   python app.py
   ```

3. Откройте в браузере: <http://127.0.0.1:5000>

## Основные формулы

### Равномерное движение
- `v = s / t` — скорость
- `s = v * t` — путь
- `t = s / v` — время

### Равноускоренное движение
- `v = v0 + a*t` — скорость
- `s = v0*t + (a*t²)/2` — путь
- `a = (v - v0) / t` — ускорение

### Свободное падение (g = 9.8 м/с²)
- `v = g*t`
- `h = (g*t²)/2`
